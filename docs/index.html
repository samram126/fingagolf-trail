Fingagolf Trail

A Claude skill that draws a red shot-tracer trail on your finger golf clips, like a golf broadcast. You send Claude a clip, Claude watches the shot frame by frame and sends back the video with the ball's flight drawn on.

Download the skill

Version 1.2 · 4 October 2026 · works with any Claude plan

Add it to Claude

  1. On claude.ai, open Settings → Capabilities and turn on Code execution and file creation.
  2. Go to Customize → Skills, tap +, then Create skill → Upload a skill.
  3. Pick the fingergolf-trail.zip you downloaded. Don't unzip it.

Use it

  1. Start a new chat and attach a clip of a shot.
  2. Ask for a trail, for example add a trail to this. Want a different look? Say so: make it a thick yellow trail.
  3. Claude finds the ball, checks the trail sits on it, and sends back the new video. If it picked the wrong shot or lost the ball, just say so in the chat.

Best results: phone held still, ball clearly visible, one shot per clip. Several clips in one chat works too.

Getting updates

The skill keeps improving. When there's a new version here, download it, delete the old one in Customize → Skills, and upload the new zip.

What's new

  • 1.2 — Every video is trimmed to the shot: it starts just before the hit and ends just after the ball lands, with the sound kept in sync. Ask for the full clip if you want it.
  • 1.1 — Pick the trail's colour and thickness. Ask for it in your message (thick blue trail), or ask for a change after; Claude redraws without re-tracking. Red and medium by default.
  • 1.0 — First shared version: lofted shots, rolls, chips, shots filmed head-on, flights that leave the picture, white balls on a white rug.
