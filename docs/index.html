Fingagolf Skills

Two Claude skills for finger golf videos. Trail draws a red shot-tracer on a clip, like a golf broadcast. Shorts turns a round into scored YouTube Shorts. You send Claude your clips in a chat and it sends the finished videos back.

Add a skill to Claude

  1. Download the skill's zip below.
  2. On claude.ai, open Settings → Capabilities and turn on Code execution and file creation.
  3. Go to Customize → Skills, tap +, then Create skill → Upload a skill.
  4. Pick the zip. Don't unzip it. Do the same for the other skill if you want both.

Works with any Claude plan, including free. See which model and effort to use.

Fingagolf Trail

Adds a shot-tracer trail that follows the ball from the hit to where it lands, and trims the video to the shot.

Download Trail

Version 1.3 · 4 October 2026

How to use it

  1. Start a new chat and attach a clip of a shot (or several).
  2. Ask for a trail, for example add a trail to this. Want a different look? Say so: make it a thick yellow trail.
  3. Claude finds the ball, checks the trail sits on it, and sends back the video, cut from just before the hit to after the ball finishes. If it picked the wrong shot or lost the ball, just say so in the chat.

Colours: red, orange, yellow, gold, lime, green, cyan, blue, purple, pink, magenta, white, black, or any hex code. Thickness: thin, medium, thick, extra thick. Ask for the full clip if you don't want it trimmed.

Best results: phone held still, ball clearly visible, one shot per clip.

Fingagolf Shorts

Turns a round, filmed one clip per shot, into vertical YouTube Shorts with a live scoreboard, BIRDIE / PAR pop-ups, drop tags and a big title.

Download Shorts

Version 1.0 · 4 October 2026

Before you start

  • Film one clip per shot. Each file name needs the shot number in it, like shot_251.mp4; the clips are put in order by that number.
  • For trails in your Short, run the clips through Trail first. Shorts uses the trail version of a shot when it has both.

How to use it

  1. Start a new chat and attach all the clips from the round (a zip works too). Ask make shorts from these.
  2. Claude checks for missing shot numbers and suggests which clips make up each hole. Confirm or correct it, and tell it the par and your score for every hole, plus any drops (+1 stroke) and which clip was played from the drop.
  3. Pick the look: the title on screen from the first frame, a small caption under it (or none), and the colours (Classic red, Ocean blue, Golf green, or your own).
  4. Optional: a highlight, like zooming in on a crazy putt or opening the video with it in slow motion.
  5. Claude builds the videos (3 holes each unless you say otherwise) and sends them back. A second video can carry on the hole numbers and total from the first.
  6. Want a change? New title, colour, par or score: just ask and it rebuilds.

Dead time, like walking between putts, is cut out. The original sound is kept so you can talk over it.

Which model and effort to use

Pick both in the chat: tap the model name next to the send button, then choose the model, and under Effort the level. Higher effort thinks longer and gets better results on hard clips, but uses up your Claude usage faster.

  • Trail: Opus on High effort works best, especially for tricky clips (a white ball on a white rug, shots toward the camera, finger flicks). Sonnet is usually fine for easy clips. If a trail keeps landing on your hand or arm, try again on Opus, or raise the effort to Extra high or Max for that one clip.
  • Shorts: Sonnet on Medium effort is enough. It mostly asks you questions and runs a ready-made script.

On the free plan

The free plan doesn't include Opus, so use Sonnet: High effort for trails, Medium for Shorts, and avoid Max. Usage resets every five hours, and a trail uses a lot of it, so expect only a few clips at a time. Keep clips short and do one clip per chat to stretch it further. Pro gives at least 5 times more usage and adds Opus.

These are our recommendations, not measured results. Plan details can change; see Claude's pricing and effort settings pages.

Getting updates

The skills keep improving. When there's a new version here, download it, delete the old one in Customize → Skills, and upload the new zip.
